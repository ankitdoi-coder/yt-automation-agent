### 2.4 Audio Engineering & Sound Design Specifications

The audio pipeline must be upgraded from low-bitrate mathematical synthesis to professional studio broadcast standards.

```
+------------------------------------+--------------------------+------------------------------------+
| Audio Parameter                    | Current Flawed Pipeline  | Prescribed Production Standard     |
+------------------------------------+--------------------------+------------------------------------+
| Master Sample Rate                 | 24,000 Hz (-ar 24000)    | 48,000 Hz (-ar 48000)              |
| Channel Layout                     | Mono (-ac 1)             | Stereo (-ac 2)                     |
| Audio Codec & Bitrate              | AAC 64 kbps              | AAC-LC 192 kbps (-b:a 192k)        |
| Voice Loudness Normalization       | Inconsistent             | -14.0 LUFS integrated (-1.5 dB TP) |
| Voiceover Speed Cadence            | 1.25x (Robotic rush)     | 1.02x to 1.05x (Natural clarity)   |
| Countdown Timer SFX                | 1200Hz sine clicks       | Authentic Foley mechanical clock   |
| Answer Reveal SFX                  | Metallic 880Hz sine ping | Studio brass tubular bell chime    |
| Background Music (BGM)             | Procedural sine waves    | Tension ambient music at -24 dBFS  |
| Dynamic Sidechain Compression      | None (Static amix)       | Automated 6dB ducking during voice |
+------------------------------------+--------------------------+------------------------------------+
```

#### Prescriptive FFmpeg Audio Mixing Filtergraph:
```bash
# Production Audio Chain with Sidechain Compression & Studio Loudnorm
ffmpeg -y \
  -i voiceover.wav \
  -i tension_bgm.wav \
  -i countdown_tick.wav \
  -i reveal_ding.wav \
  -filter_complex "\
    [1:a]volume=0.15[bgm]; \
    [0:a]asplit=2[voice_main][voice_sidechain]; \
    [bgm][voice_sidechain]sidechaincompress=threshold=0.08:ratio=4:attack=20:release=250[ducked_bgm]; \
    [voice_main][ducked_bgm]amix=inputs=2:duration=first:dropout_transition=0[dialogue_mix]; \
    [dialogue_mix][2:a]amix=inputs=2:duration=first[with_ticks]; \
    [with_ticks][3:a]amix=inputs=2:duration=first[full_mix]; \
    [full_mix]loudnorm=I=-14:TP=-1.5:LRA=7,aresample=48000[out]" \
  -map "[out]" -c:a aac -b:a 192k -ar 48000 -ac 2 final_master_audio.m4a
```
